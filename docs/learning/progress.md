## Roadmap: things we'll learn along the way

Not in order, and not all at once. These come up naturally as we build.

**The basics**
- What a website actually is (HTML, CSS, JavaScript)
- The terminal and running commands (`npm run dev`)
- VS Code: files, folders, saving, the file explorer
- Reading error messages without panicking

**Building pages**
- HTML elements and semantic tags
- Styling with Tailwind classes
- Design tokens (our color palette in `globals.css`)
- Components and props
- Pages and routing (folders in `app/` become URLs)
- Images and fonts
- Responsive design (looking good on phones)
- Accessibility (making the site usable for everyone)

**Saving and sharing work**
- Git: commits, history, undo
- GitHub: pushing your code
- Vercel: deploys, preview URLs, the live site
- Environment variables and keeping secrets safe

**Making it do things**
- Server vs. client components
- Databases (Neon)
- File storage (Cloudflare R2)
- Sending email (Resend)
- Signing in (Google OAuth)
